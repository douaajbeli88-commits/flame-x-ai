# flame-x-ai
Système de détection de feu par intelligence artificielle, conçu pour être embarqué sur un drone.

## Objectif
Détecter rapidement une zone enflammée dans un espace ouvert (usine, entrepôt) et transmettre un signal d'alerte pour accélérer l'intervention.

## Fonctionnement
- Un modèle de détection d'objets est entraîné sur un dataset d'images de feu (1542 images, Roboflow).
- Le drone survole la zone et analyse la vidéo en temps réel.
- Quand une flamme est détectée, une alerte est envoyée avec la position de la zone touchée.
